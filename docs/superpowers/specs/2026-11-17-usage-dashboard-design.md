# 用量统计设计

## 目标与范围

在现有本地控制台显示通过本提供器产生的总用量及各应用 Key、各模型用量。支持 24 小时、7 天和 30 天范围，使用折线图展示趋势；指向或选择时间点时显示该时间段的输入、输出和总 Token、请求数及金额。支持按 Key 和模型筛选，并显示范围内汇总。时间范围按本机时区展示，数据记录时间使用 UTC。

## 数据与统计

在认证完成的请求路径识别稳定的 Key 标识，不记录明文密钥或请求内容。记录实际路由模型、时间、请求状态及上游提供的用量和费用；流式与非流式路径均须覆盖，保证每次请求最多计入一次。上游未提供用量、请求中断或失败的情况单独计数，不将未知当作零。记录持久化于本地提供器的数据目录，重启后仍可查询；删除或修改 Key 不改变历史数据归属。启用之前的数据不可凭空恢复。

## 金额

优先使用可确认币种和口径的上游实际费用。提供按模型配置输入、输出单价及币种的方式，用对应的 Token 数估算费用并明确标注估算；价格变动只影响之后的新记录。没有可靠用量、单价或币种时显示未知，不将不同币种直接相加。SIWC 套餐费用和剩余额度只有在上游确实提供且语义可验证时才显示，不能把估算金额称为账单。

## 界面与安全

控制台新增用量视图，展示总量、筛选项和有明确单位及时间刻度的折线图；24 小时按小时聚合，7 天与 30 天按天聚合。图表支持键盘或表格方式访问具体时段，空数据、部分数据和错误均有清晰提示。管理接口沿用现有控制台认证机制，不暴露 Key 明文。

## 验证

使用受控上游验证普通与流式响应、多个 Key 和模型、失败与缺失用量、费用来源、价格变更、重启持久化和时间边界；检查图表的时间范围、筛选、时段详情、无数据状态及窄屏可用性。不得声称模拟数据等同上游真实账单。
